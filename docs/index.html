关于 200KB 目标

复杂或多页文件可能无法达标。工具会保留更小的结果，并如实标注大小。

勾选后使用上方目标大小与压缩偏好；PDF 转图片时，每张图片分别计算。PNG / WebP 保持所选格式。TXT 保留完整文本，超出目标时会提示。

可选择仅转换或转换后压缩；不保证所有文件达标。TXT 不保留排版；扫描版 PDF 需 OCR。暂不支持 PDF 转 Word、Word 转 PDF。
